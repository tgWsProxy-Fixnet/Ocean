01 / Как это работает

От папки с кодом до готового вывода — четыре шага

01

Загрузка

Перетащите файлы, выберите папку или подключите репозиторий. Ocean сам распознаёт язык по расширению и строит карту проекта.

drag-and-drop · Git · архивы
02

Анализ

Код нормализуется (пробелы, регистр, имена переменных) и разбивается на «отпечатки». Каждая пара файлов сравнивается по этим отпечаткам — переименования и перестановки не спасают.

шинглы · winnowing · AST
03

Отчёт

Таблица пар с процентом совпадения, отсортированная по убыванию. Рядом — двухпанельное сравнение с подсветкой одинаковых строк, как в diff.

PDF · HTML · Markdown
04

Выводы

Фильтры по порогу совпадения, история проверок и выгрузка для дисциплинарной комиссии или код-ревью. Решение остаётся за человеком — Ocean лишь показывает факты.

пороги · история · экспорт

02 / Возможности

Всё, чтобы сравнение кода было быстрым и доказательным

Подсветка одинаковых фрагментов

Двухпанельное сравнение с выравниванием по строкам: совпадения выделены бирюзовым, уникальный код — тёплым. Видно сразу, что скопировано, а что написано заново.

if user_input == secret:
print("access denied")
return False
if answer == key:
print("access denied")
return False

Процент совпадения

Для каждой пары файлов — точная метрика по общим фрагментам с настраиваемым порогом «подозрительности».

helpers.js ↔ utils.js61%

Интеграция с Git и CI

Ocean встраивается в пайплайн: после каждого push проверяются изменённые файлы, а при совпадении выше порога пайплайн падает со ссылкой на отчёт.
