    Почему это просто работает

    Никаких конфигов, портов и ключей. Утилита делает одну вещь — и делает её незаметно.

    Включение в один клик

    Один тумблер в интерфейсе — туннель поднимается за пару секунд. Столько же нужно, чтобы его выключить.

    toggle → tunnel up: ~2s

    Работает без настроек

    Не нужно вводить адрес сервера, порт или ключи. Установил, запустил, переключил — всё.

    config files: 0

    Не ломает другие программы

    В туннель уходит только трафик Telegram. Браузер, игры и остальные приложения даже не заметят, что прокси включён.

    маршрут: только telegram

    Низкая задержка

    WebSocket-туннель почти не добавляет пинга — сообщения и медиа грузятся так, будто блокировки нет.

    Поддержка всех версий Telegram

    Официальный Telegram Desktop, Portable-сборка, версия из Microsoft Store — тумблер работает с любой.
